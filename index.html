About the AI Teleprompter Project

Designed and built by Diwakar Pratap to solve cognitive overload during high-stakes technical interviews, live architecture reviews, and client presentations.

THE ENGINEERING PROBLEM

Why Browser Extensions & Second Monitors Fail

Traditional AI tools force you to alt-tab, copy-paste transcripts, or look away at a secondary monitor—breaking eye contact and introducing 5–10 seconds of awkward silence. Furthermore, browser extensions only capture audio inside a single browser tab and cannot listen to native desktop apps like Zoom, Microsoft Teams, or Webex.

AI Teleprompter operates at the OS level: an always-on-top, frameless Electron glass layer paired with a high-concurrency Python FastAPI engine that taps directly into Windows WASAPI hardware audio loopback.

CORE SUBSYSTEMS SPECIFICATION

Under the Hood

Desktop Overlay Shell Electron 33 + React 18 + TypeScript + Zustand state stores with frameless transparent windowing and Win32 click-through mouse forwarding.
Audio Capture & VAD Dual-stream Windows WASAPI Loopback (`pyaudiowpatch` / `sounddevice`) + Microphone stream with RMS energy Voice Activity Detection and acoustic echo deduplication.
Hybrid Speech-to-Text Unified Transcriber combining Google Speech-to-Text (`en-IN` / `en-US`) with local CPU `faster-whisper` (`tiny.en`) fallback for uninterrupted transcription.
RAG Knowledge Engine ChromaDB vector embeddings + SQLite FTS5 BM25 full-text search over ingested PDFs, resumes, and technical notes.
Real-Time Event Bus Bidirectional WebSocket (`ws://127.0.0.1:8765/ws/events`) with epoch-controlled task cancellation and lock-protected token streaming.
